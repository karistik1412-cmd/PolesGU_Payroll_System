# Как запустить систему (кратко)

## Что запускать

В решении два проекта, и порядок важен:

| Проект | Что это | Запускать |
|---|---|---|
| `PayrollServer` | консольный сервер, работает с базой | **первым**, оставить окно открытым |
| `PayrollClient.Wpf` | окно программы (WPF) | **вторым** |

Если нажать F5, запустится только **выделенный жирным** проект в «Обозревателе решений».
Сейчас там стоит `PayrollServer` — поэтому открывается только консоль сервера, а окна программы нет.
Это не ошибка программы.

## Способ 1 (рекомендуется): запуск двух проектов сразу

1. В «Обозревателе решений» щёлкните **правой кнопкой по решению** `PolesGU_Payroll_System` →
   **«Настроить запускаемые проекты…»** (Configure Startup Projects).
2. Выберите **«Несколько запускаемых проектов»** (Multiple startup projects).
3. У `PayrollServer` в колонке «Действие» поставьте **«Запускать»** (Start).
4. У `PayrollClient.Wpf` поставьте **«Запускать»** (Start) — и стрелками поднимите его **ниже** сервера,
   чтобы он стартовал вторым.
5. «ОК» → F5. Откроется консоль сервера и окно входа.

Строка подключения к SQL задаётся в `PayrollServer/Database/DbConnection.cs`.

## Способ 2: по одному

1. В «Обозревателе решений» щёлкните правой кнопкой по `PayrollServer` → **«Назначить запускаемым проектом»** → F5.
   Дождитесь в консоли:
   ```
   [СЕРВЕР] Запущен на порту 8888. Ожидание клиентов...
   ```
2. Не закрывая консоль, щёлкните правой кнопкой по `PayrollClient.Wpf` → **«Отладка» → «Запуск нового экземпляра»**
   (Debug → Start New Instance). Откроется окно входа.

## Вход в систему

```
логин:  admin
пароль: admin123
```

Если в консоли сервера написано `[СЕРВЕР] Учётные записи найдены: N` — значит пользователи уже есть.
Тогда подойдёт тот логин, который был создан раньше, или `admin` (если его добавляли).
Список пользователей можно посмотреть в SQL:

```sql
SELECT u.UserID, u.Login, r.RoleName
FROM dbo.Users u JOIN dbo.Roles r ON u.RoleID = r.RoleID;
```

Если пароль забыт — удалите запись и перезапустите сервер, он создаст `admin` заново:

```sql
DELETE FROM dbo.Users WHERE Login = 'admin';
```

## Если окно программы не появилось

Клиент ведёт журнал запуска:

```
%LOCALAPPDATA%\PolesGU\PayrollSystem\client.log
```

Вставить путь в проводник можно целиком — он откроет файл.
В журнале по шагам видно, до чего дошёл клиент:

```
=== Запуск клиента === 28.11.2026 13:10:02
Словарь переводов готов
Тема загружена
Конвертеры зарегистрированы
Язык интерфейса: ru
Окно входа показано
```

Если последняя строка — не «Окно входа показано», значит ошибка на этом шаге;
дальше в журнале будет полный текст исключения. Пришлите файл — по нему причина видна сразу.

## Если не подключается к базе

Сервер при старте пишет `[УСПЕХ] Подключение к БД установлено` или `[ОШИБКА] Нет подключения к БД`.
Строка подключения — в файле `PayrollServer/Database/DbConnection.cs`:

```csharp
Server=localhost\SQLEXPRESS;Database=PolesGU_Payroll;Trusted_Connection=True;
```

Если экземпляр SQL Server называется иначе — поправьте `Server=`.
